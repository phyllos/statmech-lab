# 架构

[English](../en/architecture.md) · 简体中文 · [项目介绍](README.md)

应用将科学计算与 Streamlit 分离。页面负责连接参数、计算与图形，不另行定义数学约定。

| 模块 | 职责 |
| --- | --- |
| `physics.py` | 纯模型、局部随机数、统计摘要与直方图归一化 |
| `state.py` | 页面切换时保留会话内参数 |
| `distribution_ui.py` | 统一分布名称、原始参数与说明 |
| `i18n.py` | 语言选择与双语文本 |
| `shared.py` | 图形配置、指标读数、标题及 HTML 导出 |
| `plot_theme.py` | 交互与静态图共用语义配色 |
| `styles/app.css` | 响应式布局、间距、颜色与参数栏定位 |
| `interactions.py` | 保留对照及抽样演示 |
| `labs/` | 各实验的控件与图形组合 |
| `glossary.py` | 双语定义与相关术语 |
| `app.py` | 导航、状态恢复与页面组合 |
| `export_figures.py` | 共享数值模型的批量科学出图 |

## 数据流

1. 恢复保存的参数，再渲染所选页面。
2. 从控件读取稳定模型标识与数值设置。
3. 调用 `physics.py` 计算，显式传入局部随机种子。
4. 使用完整精度数组绘图，仅在展示层格式化读数。
5. 在页面或语言切换触发控件清理前保存参数。

直方图始终按完整样本数归一化。`histogram_density` 支持显式非等宽分箱；`sample_histogram` 负责常用视窗和等宽分箱。保留对照与当前实验共用分箱，各自使用对应的完整样本数。

## 状态与缓存

控件标识、模型名称与随机种子不依赖语言。参数与对照属于 Streamlit 会话，不持久化为用户资料；新的会话不会自动恢复旧样本。URL 参数只指定页面和语言。

CLT 缓存按全部实验参数保存确定性数值结果，可在会话间共享；控件及对照状态仍在各自会话内。新增缓存函数应显式接收参数，避免读取隐含会话状态或使用全局随机数生成器。

默认参数由 `state.initialize_controls` 在缺失时初始化，绑定 key 的控件不再同时传入显式 `value`。恢复后的会话值是唯一取值来源；激发态数量等依赖边界的值在创建控件前调整到有效范围。

## 新增实验

- 在 `physics.py` 或专用纯函数模块中实现计算，为已知极限和适用条件添加测试。
- 在 `labs/` 下实现 `render()`，复用 `chart`、`metric_row`、稳定控件 key 与双语标签函数 `tr`。
- 在 `app.py` 中增加导航与页面选择，在 `state.py` 中登记控件前缀，在 `glossary.py` 中登记相关术语。
- 验证重新抽样、语言切换、术语表导航和理论不适用的情形；不能用样本估计替代不存在的总体矩。
- 新增顶层模块或资源时，检查 Docker 运行时文件清单。

## 验证

```bash
uv sync --locked
uv run --locked ruff check .
uv run --locked ruff format --check .
uv run --locked pytest -q
```

数值测试验证归一化、已知矩、适用条件和小系统精确结果；AppTest 验证交互路径与绘图数据。参数栏定位、提示框、响应式排布和 Plotly 悬浮效果仍需要浏览器目测，AppTest 不渲染 CSS。

## 代码风格

Ruff 作为开发依赖锁定。Python 统一采用四空格缩进、100 字符目标行宽和有序导入。较长教学文本允许超过目标行宽，以保留完整语义。使用 `uv run --locked ruff format .` 格式化，使用 `uv run --locked ruff check .` 检查导入和基础代码问题。CSS 使用展开的声明块与两空格缩进。

文档描述项目行为与可复现操作。参考说明使用客观陈述，操作指南使用直接步骤，版本说明使用“采用、增加、修复”等简洁表述。中英文内容保持对应，不包含对话历史、个人任务进度或未经验证的发布声明。

详细说明放在 `docs/en/` 与 `docs/zh-CN/`，对应文件保持同名。根目录 `README.md` 和 `CHANGELOG.md` 为英文入口，对应中文版位于 `docs/zh-CN/`。行为或发布内容变化时同步更新两种语言，保持对应页面的切换链接有效。

## 响应式控制面板

`shared.control_panel` 使用同一组参数和抽样控件。参数默认展开，各尺寸均可收起，并保留会话选择。按面板实际可用宽度切换排版：宽于 680px 时参数开关靠左、操作靠右；窄面板固定两列，首行是参数／抽样，次行是显示／对照。可选操作不会留下孤立按钮。窄面板或短窗口限制参数区域高度，菜单位于滚动区域之外；已保存对照的状态放在弹窗内部，保持入口宽度稳定。固定分布参数直接显示在选择框；坐标对齐时在图表附近说明，避免把原始参数与转换后的坐标混淆。

导航使用按语言区分的控件 key 和经过校验的规范页面标识。显示尺度与抽样步骤使用必须保留选中项的分段控件，切换翻译后保持逻辑取值。

独立 HTML 导出在渲染时捕获图形和语言配置，下载时才生成文件；后台工作线程不读取会话状态。

## 视觉语义

图题与简短说明使用 Plotly 原生文字，预留工具栏空间并按中英文换行；SVG 与 HTML 导出保留相同图题，Matplotlib 出图共享 `plot_theme.COLORS`。

总体矩用 `nan` 表示未定义、`inf` 表示发散；方差需有有限均值，标准化偏度与峰度需有有限方差。显式直方图范围必须有限且严格递增；常量样本的兜底仅用于自动范围。

在分布与箱型图实验中，青色表示总体理论及选中概率区间；橙色表示样本；紫色标记样本围栏外观测；灰色点线表示围栏。CDF 端点使用青色配白描边。概率区间与样本围栏独立，围栏开关仅控制辅助线与标签，围栏外观测不等于错误数据。分布名称、原始参数与对照说明由 `distribution_ui.py` 统一生成，计算约定仍属于 `physics.py`。

## 手动界面检查

- 切换语言及往返页面后保留实验、参数和显示尺度。
- 检查桌面、窄屏及矮屏，包含参数展开时滚动，确认控件不重叠、图表有可用空间。
- 检查抽样、保留对照和 HTML 下载。
- 检查手机图例、四分位标注、悬浮或触控读数，以及区间／围栏配色的区分。
- 记录实际检查的浏览器、尺寸与场景；注明未验证项，不能用 AppTest 通过代替视觉检查。
