# 版本说明

## 未发布

## v0.1.1

- 增加 GitHub Actions 检查，在 PR 和推送 `main` 时运行 Ruff、格式检查与 pytest。
- 分离英文与简体中文文档，并提供对应页面的语言切换链接。
- 开发与部署采用 Python 3.12，通过 `.python-version` 指定 uv 解释器，Docker 使用一致版本。
- 增加 Streamlit Community Cloud 部署说明，本地监听设置与共用服务配置分离。
- 切换语言后保留当前实验、显示尺度与抽样演示进度，语言控件保持单项选中。
- 实验使用共用参数面板，桌面操作靠右，窄面板工具栏分为两行；参数默认展开，可收起。
- 统一分布名称、原始参数与对照说明，标注固定参数和对齐坐标。
- 区分未定义与发散的总体矩，覆盖 Student t 与 Pareto 边界；拒绝非法显式直方图范围。
- 交互与静态图共享配色；CDF 端点采用青色白描边，围栏外观测使用紫色，围栏开关控制辅助线与标签。
- SVG 与 HTML 导出保留换行图题和简短说明；按需生成交互图 HTML，下载不触发实验重跑。
- 改善辅助文字对比度，修正 Pearson 大小写，统一“粒子数反转”术语。
- 扩展交互与状态回归测试，提供手动界面检查说明。

## v0.1.0 — 初始基线

- 四个交互实验：分布与箱型图、偏度与峰度及尾部、大数定律与中心极限定理、微观态与熵。
- 中英双语界面、可搜索术语表与相关数学解释。
- 可复现抽样、概率区间联动、保留结果对照及逐步 CLT 抽样演示。
- 紧凑读数、按需说明与响应式图表布局。
- 页面与语言切换保留会话参数，控件使用统一的初始化来源。
- 应用与科学出图共享纯数值模型；状态、展示组件及样式独立组织。
- 数值与交互回归测试、Ruff 格式和检查规则，以及锁定的 Python 依赖。
- Docker 配置与部署文档。
